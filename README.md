# Zoo World

Тестовое задание для **Sakura Games** на Unity. На площадке появляются
лягушки и змеи: лягушки прыгают, змеи ползают и едят других животных.
За симуляцией можно наблюдать, ставить её на паузу и запускать заново.

## Что сделано

- Лягушки служат добычей, змеи — хищниками. Змея съедает лягушку при
  столкновении. Если сталкиваются две змеи, выживает та, которая появилась раньше.
- Животные появляются через случайные интервалы. Для каждого выбирается
  свободное место с учётом других животных, препятствий и границ площадки.
- Прыжки, падения и столкновения обрабатывает физика Unity. Животные меняют
  направление, отскакивают от препятствий и возвращаются к центру, если вышли за границы.
- На панели видны время, число живых животных и потери по пищевым ролям.
  При поедании над хищником появляется анимированная надпись.
- Кнопки **Pause / Resume** и **Restart** позволяют приостановить,
  продолжить или начать симуляцию заново.

## Подход к реализации

У каждого вида есть prefab, пищевая роль и профиль движения. Их можно
сочетать: например, назначить одному prefab разные способы движения.
Чтобы добавить вид с уже готовым движением, достаточно настроить assets.

Код разделён по задачам: спавнер выбирает, когда и кого создать,
популяция хранит животных и считает потери, отдельные классы отвечают
за движение, правила поедания, время и интерфейс.

Зависимости передаются через VContainer. Общие сервисы создаются на время
работы приложения, объекты симуляции — на время жизни сцены.
ScriptableObject хранят настройки, а состояние и таймеры у каждого животного
свои, поэтому общий профиль движения можно использовать для нескольких видов.

HUD получает изменения через R3. Надписи поедания берутся из пула
и возвращаются в него после анимации. При отключении интерфейса подписки
снимаются, при уничтожении объектов освобождаются и анимации.

## Запуск

> **Основная сцена — [Main](Assets/_Project/Scenes/Main.unity).**
> Путь в проекте: `Assets/_Project/Scenes/Main.unity`.

1. Установите **Unity 6000.3.27f1** через Unity Hub.
2. Подготовьте Git LFS командой `git lfs install` и клонируйте репозиторий.
   Если он уже скачан, выполните `git lfs pull` в корневой папке проекта.
3. Добавьте папку проекта в Unity Hub, откройте её и дождитесь импорта ресурсов
   и восстановления пакетов. Для первого открытия нужен доступ к интернету.
4. Откройте сцену **Main** и нажмите **Play**. Симуляция запустится автоматически.

Управление находится на панели в правом верхнем углу:

| Кнопка | Действие |
|---|---|
| **Pause / Resume** | Поставить симуляцию на паузу или продолжить её |
| **Restart** | Начать симуляцию заново |

Для сборки откройте **File → Build Profiles**, выберите платформу и при
необходимости установите её модуль через Unity Hub. Main уже включена
в список сцен сборки. Сохранений между запусками нет.

## Архитектура

Код игры находится в [Assets/_Project/Runtime](Assets/_Project/Runtime)
и собирается в `Project.Runtime`. Рядом расположены `Scenes`, `Prefabs`
и `Settings`; внешние зависимости находятся в `Packages` и `Assets/ThirdParty`.

| Папка | Что в ней |
|---|---|
| `Composition` | Регистрация зависимостей в ProjectLifetimeScope и MainLifetimeScope |
| `Simulation` | Игровые часы, пауза, перезапуск и связь с HUD |
| `Population` | Появление животных, поиск места и учёт популяции |
| `Actors` | Определения видов, создание экземпляров и события физики |
| `Actors/Movement` | Профили движения, индивидуальное поведение и Rigidbody-мотор |
| `Actors/Contacts` | Правила поедания |
| `Space` | Границы площадки, навигация и препятствия |
| `UI` | HUD и пул надписей поедания |

`ActorSpawner` выбирает вид, `ActorSpawnPlacement` находит место,
а `ActorFactory` создаёт животное по `ActorDefinition`. Профиль движения
создаёт для него отдельный `IMotionBehaviour`; `ActorMovement` вызывает это
поведение на каждом физическом шаге.

`ActorPopulation` хранит животных и статистику, `PredationRules` определяет
возможность поедания. `SimulationController` связывает популяцию, часы и HUD
и управляет паузой через масштаб времени Unity.

## Настройка

Параметры доступны в Inspector. Пути ниже указаны относительно `Assets/_Project`.

| Где | Что настраивается |
|---|---|
| `Settings/Zoo/Population.asset` | Состав видов, интервалы появления и размещение |
| `Settings/Zoo/Actors` | Prefab, пищевая роль и профиль движения вида |
| `Settings/Zoo/MotionProfiles` | Параметры прыжкового и линейного движения |
| `Settings/Zoo/Physics/ActorPhysics.asset` | Восстановление скорости после столкновений |
| `Prefabs/Actors` | Тела и внешний вид животных |
| `Prefabs/UI` | Оформление интерфейса и надписей |

## Как добавить животное

1. Скопируйте Frog или Snake из `Prefabs/Actors`
   и измените дочерний объект **Visual**. Сохраните Actor и его ссылки
   **Visual**, **Rigidbody**, **Collider**.
2. Создайте определение вида через **Create → Zoo → Actor definition**
   и назначьте **Prefab**, **Role** (`Prey` или `Predator`) и **Motion**.
3. Выберите готовый профиль движения или создайте его через
   **Create → Zoo → Motion → Hop** либо **Linear**. Для прыжка задайте
   положительные расстояние, высоту и интервал; для линейного движения —
   скорость и интервал смены курса.
4. Добавьте определение в список **Actor Definitions**
   у `Population.asset`. Все записи выбираются с равной вероятностью.
5. Запустите Main и проверьте появление, движение,
   столкновения, поедание, паузу и перезапуск. В Console не должно быть ошибок.

<details>
<summary>Если вы изменяете физическое тело prefab</summary>

Сохраните единичный масштаб корня, динамический Rigidbody с гравитацией
и SphereCollider. Вращение тела должно быть заблокировано, движение по Y —
свободно. Дочернему Visual коллайдеры не нужны.

Подберите радиус под размер животного и расположите центр сферы на высоте
`radius - 0.05` над корнем, как в исходных prefab.

</details>

### Новый способ движения

Реализуйте `IMotionBehaviour` в `Actors/Movement/Behaviours` и добавьте
наследника `MotionProfile` в `Actors/Movement/Profiles`. В `CreateMovement`
создайте отдельное поведение для каждого животного и передайте его общему
`ActorMovement` вместе с мотором и навигацией.

Движение и размещение рассчитаны на наземных животных в плоскости XZ.
Для полёта или плавания может потребоваться расширить навигацию и размещение.
